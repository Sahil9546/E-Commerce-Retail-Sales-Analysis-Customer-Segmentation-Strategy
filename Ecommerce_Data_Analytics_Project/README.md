# E-Commerce Sales Performance & RFM Segmentation Project

## Project Structure
- `Data/`: Raw, cleaned, and RFM segmented datasets.
- `Notebooks/`: Python Jupyter Notebook with EDA and feature engineering.
- `Dashboards/`: Dashboard design blueprints and visual metrics layout.
- `Report/`: Full written project report and findings.

## How to Run
1. Navigate to `Notebooks/` and open `Ecommerce_Sales_RFM_Analysis.ipynb`.
2. Execute cells to inspect data and rerun segmentation logic.
3. Import `Data/Cleaned_Online_Retail.csv` into Power BI / Tableau to interact with the dashboard.

# E-Commerce Retail Sales Analysis & Customer Segmentation Strategy

## Project Overview
This project provides an end-to-end data analysis and customer segmentation framework for an e-commerce retail platform. By leveraging sales transaction history, the project identifies key revenue drivers, evaluates customer purchasing behaviors, and groups customers into targeted segments using RFM (Recency, Frequency, Monetary) analysis and machine learning clustering.

---

## Key Features
* **Sales & Revenue Analytics:** Analysis of sales trends over time, top-performing product categories, revenue drivers, and order volumes.
* **RFM Customer Segmentation:** Categorization of customers based on:
  * **Recency:** Days since the last purchase.
  * **Frequency:** Total number of completed transactions.
  * **Monetary:** Total monetary value spent.
* **Predictive Clustering:** Unsupervised machine learning (K-Means Clustering) to discover distinct customer groups.
* **Strategic Recommendations:** Tailored marketing and retention strategies based on identified customer segments (e.g., Champions, At-Risk, Loyal Customers).
